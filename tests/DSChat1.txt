使用 Render 部署演示页的完整步骤
1. 准备工作：创建 Dockerfile 和 render.yaml
在你的项目根目录（即 NewsPhotos 文件夹）下，创建以下两个文件，这是 Render 构建和启动应用的关键：

创建 Dockerfile：定义应用的运行环境。

dockerfile
# 使用 Python 3.11 的轻量级镜像作为基础环境
FROM python:3.11-slim

# 设置容器内的工作目录
WORKDIR /app

# 复制依赖文件并安装
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制项目中的所有文件到容器内
COPY . .

# 暴露 8080 端口（Render 会动态分配端口，这里主要作为声明）
EXPOSE 8080

# 启动命令：使用 Gunicorn 作为生产服务器运行 Flask 应用
# 注意：`app:app` 指向你的 `app.py` 文件中的 `app` 实例
CMD ["sh", "-c", "gunicorn --bind 0.0.0.0:$PORT app:app"]
重要：请确保你的 requirements.txt 文件中包含 gunicorn，如果还没有，请添加进去。

创建 render.yaml（可选，但推荐）：让 Render 自动读取配置，省去在网页上手动填写。

yaml
services:
  - type: web
    name: news-card-generator
    env: docker
    plan: free
    region: oregon # 选择离你用户最近的区域，例如 oregon, frankfurt, singapore
    dockerfilePath: ./Dockerfile
    envVars:
      - key: PORT
        value: 8080
2. 推送代码到 GitHub
确保你新增的 Dockerfile 和 render.yaml 文件已经提交并推送到了你的 GitHub 仓库。

bash
git add Dockerfile render.yaml
git commit -m "Add Dockerfile and render.yaml for Render deployment"
git push origin main
3. 在 Render 上创建 Web Service
登录 Render Dashboard。

点击 "New +" 按钮，然后选择 "Web Service"。

在列表中找到并选择你刚刚推送的 GitHub 仓库 news-card-generator。

配置服务：如果 Render 检测到了你的 render.yaml 文件，很多配置会自动填好。如果没有，请按以下内容填写：

Name: news-card-generator

Region: 选择一个离你或目标用户最近的区域

Branch: main

Runtime: Docker

Instance Type: 选择 "Free" 免费实例

点击 "Create Web Service" 按钮。

4. 等待部署与访问
点击创建后，Render 会自动开始构建和部署。首次部署大约需要 5-10 分钟。你可以在控制台看到实时日志，当状态显示为 "Live" 时，就表示部署成功了。Render 会自动为你生成一个 https://xxx.onrender.com 格式的公开网址，点击即可访问你的演示页。

⚠️ 免费版的限制与性能优化
在使用免费版时，有几个重要的限制需要你了解，并可以据此优化你的应用。

服务休眠：如果你的应用在 15 分钟内没有任何访问请求，Render 会自动让它进入“休眠”状态以节省资源。当下次有用户访问时，服务需要“冷启动”，这个过程大约需要 1 分钟才能恢复。

资源限制：免费实例提供 512MB RAM 和 0.1 CPU，对于你的图像处理应用来说，资源是比较紧张的。

临时存储：Render 的文件系统是临时的，每次重启或重新部署，应用在磁盘上写入的所有文件（比如 uploads/ 目录）都会被清除。

数据库限制：如果你之后需要用到数据库，请注意免费版的 PostgreSQL 数据库会在创建 30 天后被删除，数据无法永久保存。

🛠️ 针对你项目的优化建议
由于你的应用涉及图像处理，强烈建议进行以下代码修改，以确保在免费版上能流畅运行：

使用 /tmp 目录：将代码中所有 os.path.join("uploads", ...) 的路径改为 os.path.join("/tmp", ...)。这是 Render 免费版唯一可写的目录。

限制图片尺寸：在将上传的图片传递给 OpenCV 或 Pillow 处理前，增加一步尺寸预处理，将图片的长边限制在 1080 像素以内。这能大幅降低内存消耗，避免 512MB 内存被撑爆。

💰 超出额度会怎样？
实例时长耗尽：免费服务会被暂停，直到下个计费周期自动恢复。

出站带宽耗尽：按 $0.15/GB 收费。但前提是你已绑定了支付方式。

内存或CPU超限：服务会因内存溢出而崩溃重启，但不会产生额外费用，仅影响可用性。

🛡️ 确保零费用的关键操作
绝对不要添加支付方式（如信用卡）：这是最核心的保障。没有绑定支付方式，即使产生超额使用量，Render 也只会禁用服务而不会扣费。

检查仪表盘用量：登录 Render Dashboard，在 Billing 页面可以查看本月的免费额度使用情况。
